# Content-Calender
This repo will hold all of my progress on learning Spring Boot, starting with my first Spring Boot project: a Content Calendar API.
 
How I'm learning
----------------
 
I'm using the YouTube crash course: [Spring Boot Tutorial for Beginners - Crash Course using Spring Boot 3](https://www.youtube.com/watch?v=UgX5lgv4uVM) by Dan Vega.
 
Why Spring Boot?
----------------
 
Coming from Android development, I've spent most of my time on the client side of apps. I wanted to understand what actually happens on the other end of those API calls, and Spring Boot is one of the most widely used ways to build backends in Java. It's also interesting to compare the two: things like how a project's directories are organized are done pretty differently in Spring Boot than in Android (by class type instead of by feature)!
 
What Exactly am I learning?
---------------------------
 
As mentioned I will be learning the basics of Spring Boot, but what exactly does that entail?
The topics include but aren't limited to:
- What Spring and Spring Boot are (and the difference between them).
- Spring core concepts: the IoC Container, the ApplicationContext, Beans, and Dependency Injection.
- Building a REST API with Spring MVC (Models, Repositories, and Controllers).
- Using a REST API from a frontend (and dealing with CORS with `@CrossOrigin`).
- Data Validation with `spring-boot-starter-validation`.
- Working with databases: the H2 Database and Spring Data JPA.
- Configuration and Profiles.
- Production-ready features with the Spring Boot Actuator.
- Deploying to production (with Railway).
Essentially, every topic that the tutorial goes over will be documented in this repo and more.
 
Tech Stack
----------
 
- Java 17
- Spring Boot 4.1.1 (the tutorial uses Spring Boot 3, so some things may look a little different!)
- Maven (with the Maven Wrapper)
- Spring Web MVC
- Spring Validation
- H2 Database (coming soon)
